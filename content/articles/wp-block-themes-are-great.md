<p>I have been working with Wordpress for many years now, including using many "Site Builders" such as <strong>Divi</strong>, <strong>Elementor</strong>, and others. But in recent years, I have committed fully to using the Wordpress core <strong>Block Themes </strong>as a base for my work. This experience has a learning curve, but I would never go back. <br><br>I find the block theme development style makes so much sense, but not just in the site building way of thinking, but also how you can extend the core functionality, without always having to use a different paradigm.</p><p>In the next few posts, I will cover some cool learnings, some that I find absolutely worth their weight in gold, and others that may need tweaking. <br><br>Let's go on this journey together</p>
